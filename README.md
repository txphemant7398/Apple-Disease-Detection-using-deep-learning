**Apple Disease Detection using Deep Learning**

Overview
A deep learning-based web application that detects apple leaf and fruit diseases using MobileNetV2 and Streamlit.

Features
1) Detects multiple apple diseases
2) Supports image upload
3) Real-time prediction
4) User-friendly interface
5) Technologies Used
6) Python
7) TensorFlow
8) Keras
9) MobileNetV2
10) Streamlit
11) NumPy
12) Pillow
13) Dataset


3160 labeled images covering:
1) Apple Scab
2) Black Rot
3) Cedar Apple Rust
4) Apple Blotch
5) Healthy Apple

Model Performance
Accuracy: 88.6%

Run Locally
pip install -r requirements.txt
python -m streamlit run website.py
